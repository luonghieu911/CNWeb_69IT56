2.3 Custom bullet dùng ::before

Dấu ✔ màu xanh qua pseudo-element ::before

  • Hiểu cú pháp HTML5 cơ bản
  • Nắm vững CSS Selector và Box Model
  • Biết cách dùng Flexbox và Grid
  • Thực hành tạo trang web responsive
  • Sử dụng được JavaScript DOM

2.5 Danh sách emoji bullet

list-style: none + ::before với emoji

  • Phát triển ứng dụng di động
  • Xây dựng API RESTful
  • Quản trị cơ sở dữ liệu
